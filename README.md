# Student Grade Tracker

A Java Swing-based Student Grade Tracker for managing student records and analyzing academic performance.

## Features

- Add student records
- Update student information and marks
- Search students by roll number
- Delete student records
- Calculate average marks
- Calculate grades automatically
- PASS/FAIL status
- Class average
- Top student analysis
- Lowest student analysis
- Input validation
- Duplicate roll-number prevention
- Interactive graphical user interface

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- ArrayList
- Arrays
- Comparator and Java Streams

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Methods
- Data management using `StudentManager`
